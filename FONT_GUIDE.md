# Guia de Fontes do Projeto

Este documento lista todas as fontes configuradas no site e suas aplicações para garantir consistência visual.

## Regras de Aplicação

| Fonte | Estilo | Aplicação |
| :--- | :--- | :--- |
| **Mea Culpa** | .mea-culpa-regular | Nome do Ateliê |
| **DM Sans** | .dm-sans | Textos e Números |
| **Pinyon Script** | .pinyon-script-regular | Títulos |
| **Parisienne** | .parisienne-regular | Nome dos Produtos |

**Proibição:** Alterações nessas diretrizes sem aprovação prévia são proibidas. Caso precise de uma nova fonte, siga o processo de atualização deste guia primeiro.
